Cache-segar adalah data tersimpan yang umurnya masih di bawah batas TTL (Time To Live) sehingga dapat langsung digunakan tanpa memanggil jaringan internet. Cache-basi adalah data tersimpan yang umurnya sudah melewati batas TTL dan digunakan sebagai cadangan tepercaya saat perangkat berada dalam kondisi offline. First-run offline adalah kondisi ketika aplikasi dibuka tanpa koneksi internet dan belum ada sama sekali data cache yang tersimpan di perangkat. Label status data sangat penting bagi pengguna agar mereka mendapatkan informasi yang jujur dan transparan mengenai kebaruan data cuaca yang sedang ditampilkan.
